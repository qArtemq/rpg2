# ⚔️ LifeQuest RPG

Превращай реальные дела в RPG: убираешь комнату — наносишь урон боссу «Лень», учишь немецкий — качаешь Intelligence, делаешь зарядку — качаешь Strength. Это playable MVP по твоей концепции — чистый HTML/CSS/JS, без сборки, открывается сразу.

## 🎮 Что уже работает

- **Персонаж**: создание (имя, класс Warrior/Mage/Rogue, аватар-эмодзи), класс даёт лёгкий стартовый бонус, но характеристики реально растут от выполненных квестов.
- **8 характеристик**: Vitality, Intelligence, Strength, Agility, Focus, Wealth, Discipline, Luck — у каждого квеста есть категория, она и прокачивается.
- **Квесты**: Daily / Side / Main (эпическая цепочка шагов) / Weekly (авто-трекинг прогресса за неделю). Свои квесты добавляются прямо в приложении.
- **Боссы**: Лень → Прокрастинация → Хаос → Долги → Экзамен → Большой проект → Неделя работы, по кругу с ростом HP. Любой выполненный квест наносит урон = его XP.
- **Экономика**: XP, Gold, Energy, Skill Points, лут с шансом выпадения целей.
- **Инвентарь**: экипировка (оружие/броня/перчатки/обувь/рюкзак/талисман) даёт бонусы к характеристикам, зелья (XP-буст, щит стрика, удача) и магазин.
- **Питомцы**: открываются за стрик/ачивки, растут от части получаемого XP.
- **Навыки**: лёгкое дерево (Focus / Discipline / Speed) за Skill Points с уровнями.
- **Streak**: не обнуляется жёстко за 1 пропуск — плавно теряет 1 день (можно защитить зельем-щитом).
- **Карта мира**: регионы открываются по уровню, клик по региону подсвечивает связанные квесты.
- **Достижения, календарь с историей по дням, статистика (за неделю и за всё время), настройки** (переименование, экспорт/импорт сохранения в JSON, сброс прогресса, reduce-motion).
- **PWA**: манифест + service worker — можно «Установить на экран» на телефоне, работает офлайн.
- Сохранение — в `localStorage` браузера (см. «Почему так» ниже).

## 🗂 Структура

```
index.html
css/style.css
js/util.js      — даты, форматирование, мелкие хелперы (без DOM)
js/data.js      — все игровые данные: классы, квесты, боссы, предметы, ачивки...
js/storage.js   — слой персистентности (localStorage), легко заменить на Supabase
js/state.js     — движок игры: вся логика начисления XP/Gold/урона/стриков/ачивок
js/ui.js        — вьюхи (Home/World/Quests/Character/Inventory) — чистые render-функции
js/modals.js    — модалки (ачивки, календарь, статистика, настройки, форма квеста) + тосты
js/app.js       — склейка: делегирование событий, роутинг, сохранение
manifest.webmanifest, sw.js, icons/ — PWA
```

Движок (`util/data/storage/state`) не трогает DOM и был прогнан через юнит-тесты в Node (создание персонажа, выполнение квестов, левел-апы, убийство босса, покупка/экипировка, зелья, достижения, сохранение/загрузка) — логика проверена.

## 🚀 Как открыть

**Локально:** просто открой `index.html` в браузере — зависимостей и сборки нет.

**Как сайт (GitHub Pages), один раз:**
1. Settings → Pages → Source: `Deploy from a branch`.
2. Branch: `main`, folder: `/ (root)` → Save.
3. Через минуту сайт появится на `https://qartemq.github.io/rpg2/`.

## 🧠 Почему не Next.js/Supabase (пока)

В исходной концепции был стек Next.js + Supabase. Для первой версии я сознательно выбрал **ванильный HTML/CSS/JS без сборки**: это 100% рабочий результат прямо сейчас, без npm-зависимостей, которые могут не собраться, без хостинга под бэкенд, нулевой риск «не завелось». `storage.js` специально выделен в отдельный слой с простым интерфейсом (`load/save/clear/export/import`), чтобы потом безболезненно подключить Supabase (синк между устройствами, аккаунты, AI-генерация квестов) — игровая логика в `state.js` его вообще не касается.
